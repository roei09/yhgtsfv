## כללי קוד
- סדר הקבצים ב-index.html חשוב: קבצי CSS מאוחרים דורסים מוקדמים, וקבצי ה-JS חולקים שמות גלובליים (נטענים עם defer לפי הסדר). מוסיפים כלל בקובץ של הנושא שלו.
- אחרי שינוי מעלים את ?v= בכל הקישורים ב-index.html כדי שהדפדפן ימשוך את הגרסה החדשה.
- הערות מסבירות למה, לא מה. בלי תוויות סבב/גרסה.

## אחרי כל שינוי ב-CSS או JS
להעלות את מספר הגרסה (`?v=…`) בכל הקישורים לקבצים ב-index.html, כדי שהדפדפנים יטענו את הקובץ החדש.

## מצבי ביצועים
האתר בוחר לבד: `full` (מחשב חזק), `balanced` (טלפון/מחשב ממוצע), `lite` (מכשיר חלש או "הפחתת תנועה").
לבדיקה: `?perf=full` / `?perf=balanced` / `?perf=lite` בסוף הכתובת.
- קודי ההנחה שבשקפי שיתופי הפעולה נקראים מ-data.js (codes), אז משנים קוד שם.
